# NPSAS Student Parents & Financial Wellness

#### This repository contains data analysis and data visualizations examining the financial experiences of undergraduate student parents using data from the 2020 National Postsecondary Student Aid Study.

The project focuses on differences in how undergraduate students with dependent children and those without use public benefits programs.

Data come from the National Center for Education Statistics (NCES) 2020 National Postsecondary Student Aid Study (NPSAS 2020). Statistics were generated using the NCES PowerStats data analysis system.
